# 03 — 条件注入机制

## 一句话开场

> 你让 AI"画一只戴帽子的猫"，它凭什么知道"猫"和"帽子"在图像里应该长什么样？文本条件怎么变成模型能理解的东西？这就是条件注入机制要回答的问题——**一个扩散模型怎么"听懂人话"（以及"看懂图"）。**

---

## 正文：渐进式理解

**第一层：问题定义。** 无条件的扩散模型只能生成随机图像（就像随机画画），而有用的生成必须有条件——文本描述、参考图像、语义布局。条件注入机制要解决：**如何将外部条件信号（文本/图像/控制信息）引入去噪过程，让生成的每一帧都遵循这个条件？** 这个问题之所以难，是因为文本是离散的语义符号，图像是稠密的像素矩阵，而扩散过程在噪声空间中操作——这三个空间的表示形式完全不同。

**第二层：核心直觉。** 想象你在指挥一个乐队：指挥的动作（条件信号）不是直接替乐手演奏，而是影响他们"怎么演"。类似地，条件注入不是直接修改生成的像素，而是**在每一步去噪中"引导"模型朝符合条件的方向走**。这里有两层引导：① 模型应该知道"在什么条件下生成"（条件嵌入）；② 模型应该"更关注条件而非随机猜测"（引导强度控制）。

**第三层：方案细节。** 条件注入分为两个独立环节：

**环节 A：条件编码 + 架构注入——把条件变成模型能用的表示**

```
文本 "A cat wearing a hat"
  → CLIP 文本编码器
    → 77 × 768 text embeddings
      → U-Net Cross-Attention 层：text_emb 做 K/V，image_feat 做 Q
        → 输出携带语义信息的 image_feat
```

对于图像类条件（参考图、控制图），处理方式类似但编码器不同（CLIP 图像编码器 / VAE 编码器）。

**环节 B：Guidance 策略——控制模型对条件的"重视程度"**

**Classifier Guidance（历史方案）：** 训练一个额外的分类器 p(y|x_t)，在采样时用分类器梯度将生成推向目标类别。需要单独训练分类器，且分类器在噪声图像上表现差。

**Classifier-Free Guidance / CFG（当前标准）：** 训练时随机丢弃条件（如 10% 概率将文本替换为空序列），让模型同时学会 p(x|cond) 和 p(x|?)。采样时做外推：
```
ε_guided = ε_θ(x_t, ?) + w · [ε_θ(x_t, cond) - ε_θ(x_t, ?)]
```
其中 w > 1 时，模型更"听话"（但多样性降低）。

**第四层：不同方案的权衡。**

| 方案 | 核心机制 | 优点 | 代价 |
|------|---------|------|------|
| **Classifier Guidance** | 条件梯度更新 | 理论简单 | 需要额外分类器，噪声上分类不准 |
| **CFG（Classifier-Free）** | 无条件+有条件混合外推 | 不需额外模型，效果优秀 | 推理需要两次前向，w 调节需经验 |
| **Cross-Attention（架构层面）** | 条件作为 K/V 注入 | 灵活融合任意条件 | 推理计算量增加 |
| **Adaptive Group Norm（机制层面）** | 条件调制归一化参数 | 计算轻量 | 表达能力有限 |

**CFG + Cross-Attention 是当前事实标准**。所有主流模型（SD、SDXL、SD3、Flux）都使用这个组合。

**第五层：总结升华。** 条件注入不再仅是一个"把文本送进去"的问题——它已经成为扩散模型**可用的核心**。没有 CFG，模型生成的结果会缺乏语义一致性；没有 Cross-Attention，文本条件无法在空间上精确影响生成的局部区域。条件注入机制的演进方向是：从"粗粒度的类别条件"→"细粒度的文本条件"→"多重异构条件（文本+图像+控制）"。

## 学习目标

读完你能：

- **写出 CFG 的采样公式**：解释 w（guidance scale）对生成质量 vs 多样性的影响
- **画出一条文本 prompt 经过 CLIP → Cross-Attention → U-Net 的完整数据流**
- **对比 Classifier Guidance 和 CFG 的优缺点**：指出为什么 CFG 成为工业标准
- **解释为什么 Cross-Attention 的 Q/K/V 分别来自哪**：Q 来自图像特征，K/V 来自文本嵌入
- **为一个新条件类型（如音频控制）设计条件注入方案**：选择编码器 + 注入位置

## 精选论文

**Ho & Salimans (2022) "Classifier-Free Diffusion Guidance" [[arXiv](https://arxiv.org/abs/2207.12598)]**

- **一句话定位**：CFG 的提出，替代了需要额外分类器的 Classifier Guidance，成为所有文生图模型的标准条件机制
- **阅读重点**：Section 3（方法描述：训练时随机丢弃条件，采样时外推）、Figure 1（CFG vs CG 对比）
- **时间分配建议**：全文仅 4 页，建议全部通读。Section 4（实验）重点看 FID vs 条件强度的 trade-off
- **与本模块的关系**：回答了"如何在不需要额外分类器的情况下实现条件控制"

**Rombach et al. (2022) "High-Resolution Image Synthesis with Latent Diffusion Models" Section 3.3**

- **一句话定位**：定义了 Cross-Attention 条件注入机制，将文本/语义嵌入通过 Cross-Attention 送入 U-Net 的核心架构决策
- **阅读重点**：Section 3.3（Conditioning Mechanisms）、Figure 3（架构细节：Cross-Attention 注入位置）
- **时间分配建议**：建议精读 Section 3.3（约 2 页），理解 cross-attention layer 在 U-Net 中的具体位置和 QKV 来源
- **与本模块的关系**：回答了"条件信号具体以什么机制注入去噪网络"
