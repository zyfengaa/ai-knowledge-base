# DDPM + 扩散数学模型 架构深度解剖

> Ho et al. (UC Berkeley, NeurIPS 2020) | "Denoising Diffusion Probabilistic Models" —— 扩散模型从理论到实用的转折点

---

## 写在前面：为什么扩散模型值得深度解剖？

2020 年之前，图像生成领域是 GAN 的天下。GAN 的核心思路是"生成器造假，判别器打假"——对抗训练确实能产生逼真的图像，但问题一直没解决：

- **训练不稳定**——G 和 D 的平衡是一门玄学
- **多样性受限**——mode collapse，模型只学会了数据分布中的部分模式
- **没有明确的概率解释**——GAN 学习的是数据分布本身，不是显式密度估计

DDPM 没有追求更复杂的对抗博弈。它回归了一个最简单的想法：**"如果一步步加噪声把图像变成纯噪声，那一步步去噪声能不能从纯噪声生成图像？"**

这个思路在 2015 年由 Sohl-Dickstein 提出过理论框架，但真正让它工作起来的配方，是 DDPM 这篇论文给出的。**DDPM 的成功不是因为发明了新的数学，而是找对了简化的工程配方。** 这篇文章就深度解剖这个配方。

---

## 一、整体流程（一张图看懂）

```
训练阶段（前向过程）:
  原始图像 x₀  →  x₁  →  x₂  →  ...  →  x_T（纯噪声）

  每一小步: x_t = √(1-β_t)·x_{t-1} + √β_t·ε
  即"保留上一张图的部分 + 加一点噪声"

推理阶段（反向过程）:
  纯噪声 x_T  →  x_{T-1}  →  ...  →  x₁  →  生成图像 x₀

  每一步: 让 U-Net 预测"图上加了什么噪声 ε_θ"，减去它再往回走一小步
```

| 角色 | 训练时 | 推理时 |
|------|--------|--------|
| 输入 | 干净图像 x₀ + 随机噪声 ε | 纯噪声 x_T（~N(0, I)）|
| 模型任务 | 预测添加的噪声 ε_θ(x_t, t) | 预测噪声 → 逐步去噪 |
| 损失函数 | MSE(ε, ε_θ(x_t, t)) | 不需要损失，迭代采样即可 |
| 步数 | 任意一步采样训练（随机选 t） | T=1000 步完整走完 |

## 二、前置条件：为什么 DDPM 之前的方案走不通

### 2.1 传统的"去噪"思路

DDPM 之前，做生成模型的直觉是：训练一个模型一次性把噪声图像恢复成干净图像。但这个思路有两个根本问题：

```
输入: 纯噪声 → 模型 → 输出: 干净图像（一步到位）

问题 1: 从"纯随机"到"确定的某一个图像"是一个高度歧义映射
         -- 一个纯噪声可以对应无数种可能的生成结果
问题 2: 模型不知道应该生成"猫"还是"狗"，没有条件约束
         -- 无条件生成完全失控
```

**DDPM 的关键洞察: 不一次做完，而是拆成 1000 小步。每一步只做"轻微去噪"。**

每一步的映射是"少量确定性的"——从 x_t 到 x_{t-1}，两张图看起来几乎一样（只有一点点噪声差异）。模型只需预测"这一步加了什么噪声"，比"从一个噪声一步画出一张图"要确定得多。

### 2.2 VAE 的遗产

DDPM 的概率建模思路来自 **VAE（变分自编码器，2013）**：

```
VAE 公式: 最大化 log p(x) 的证据下界（ELBO）

DDPM 的思路: 把 VAE 的"单步隐变量"扩展为"多步隐变量链"
            x₀ → z₁ → z₂ → ... → z_T   (VAE 是 x₀ → z)

扩散模型 = VAE 的隐变量从 1 个变成 T 个，且每一小步的转移是已知的（高斯分布）
```

这个递进关系很重要——DDPM 不是凭空冒出来的数学，它是 VAE 在"多步马尔可夫链"上的延伸。

## 三、前向过程：破坏数据（确定性的）

### 3.1 数学定义

前向过程逐步将噪声添加到数据中。每一步定义为已知的高斯转移：

```
q(x_t | x_{t-1}) = N(x_t; √(1-β_t) · x_{t-1}, β_t · I)
```

| 符号 | 含义 |
|------|------|
| x₀ | 原始图像（训练数据）|
| x_t | 第 t 步加噪后的图像 |
| β_t | 噪声调度表（0 到 1 之间的值，控制每步加多少噪声）|
| T | 总步数（DDPM 设为 1000）|
| q(x_t \| x_{t-1}) | 已知的高斯转移，**不需要学习** |

**这里有一个关键设计：方差固定为 β_t·I，不是可学习的参数。** 省掉了学习方差的负担，模型只需关注均值（即去噪方向）。

### 3.2 重参数化技巧：为什么可以任意步采样

因为每一步都是高斯转移，从 x₀ 一步到 x_t 有闭式解，不需要递推 1000 步：

```
定义: α_t = 1 - β_t
      ᾱ_t = ∏_{s=1}^{t} α_s（前 t 步的衰减累乘）

则:  q(x_t | x₀) = N(x_t; √ᾱ_t · x₀, (1 - ᾱ_t) · I)

重参数化采样公式:
  x_t = √ᾱ_t · x₀  +  √(1 - ᾱ_t) · ε
         ↑              ↑
  保留原图的比例   加噪声的幅度
```

**这个公式是 DDPM 训练的核心**——训练时不需要真的递推 1000 步，随机选一个 t，从 x₀ 直接计算出 x_t 即可。一个 batch 里不同样本可以选不同 t 并行训练。

### 3.3 噪声调度（Noise Schedule）

β_t 的选择决定加噪速度。DDPM 使用的线性调度：

```
β_t = β_start + (β_end - β_start) × (t-1)/(T-1)

其中 β_start = 1×10⁻⁴, β_end = 0.02
```

```
β_t 曲线:
  t=0      ▎0.0001    ← 几乎不加噪声
  t=250    ▎0.0051
  t=500    ▎0.0101
  t=750    ▎0.0151
  t=1000   ▎0.0200    ← 最终噪声幅度约 √0.98 = 0.99

即最后一张图 x_T ≈ 纯噪声 N(0, I)
```

**为什么线性调度？** 这是经验发现——后续工作（cosine schedule、sigmoid schedule）证明了更好的调度存在，但线性调度简单有效，足够让模型训起来。

## 四、反向过程：生成数据（模型学习的）

### 4.1 概率公式

前向过程的逆过程也是高斯分布（当 β_t 足够小时）：

```
p_θ(x_{t-1} | x_t) = N(x_{t-1}; μ_θ(x_t, t), Σ_θ(x_t, t))

DDPM 的简化: Σ_θ(x_t, t) = σ²_t · I（固定方差，不学习）
             σ²_t = β_t（或 β_t̃ = (1 - ᾱ_{t-1})/(1 - ᾱ_t) · β_t）
```

### 4.2 核心推导：要预测什么

DDPM 的关键在于参数化 μ_θ。通过变分下界推导，最优的 μ_θ 应该预测：

```
如果预测去噪的图像:
  μ_θ = (√ᾱ_{t-1} · β_t)/(1 - ᾱ_t) · x₀ + (√α_t · (1 - ᾱ_{t-1}))/(1 - ᾱ_t) · x_t

如果预测添加的噪声 ε（DDPM 的选择）:
  μ_θ = 1/√α_t · (x_t - β_t/√(1 - ᾱ_t) · ε_θ(x_t, t))

简化后采样公式:
  x_{t-1} = 1/√α_t · (x_t - β_t/√(1 - ᾱ_t) · ε_θ(x_t, t)) + σ_t · z
           ↑                                   ↑              ↑
     缩放当前图像          减去模型预测的噪声             加随机抖动
```

**DDPM 的选择：预测噪声 ε 而不是预测去噪后的图像 x₀。** 为什么？

```
对比两种参数化方式:

| 方式 | 预测目标 | 效果 |
|------|---------|------|
| 预测 x₀（去噪图像） | 直接回归像素值 | 训练不稳定，图像空间高度非线性 |
| 预测 ε（添加的噪声） | 回归高斯噪声 | 数据范围小（~N(0,1)），数值稳定 |
```

预测噪声本质上是 **"你说这一步加了什么噪声，我减去它"**——模型的工作量比"一步画一张图"小得多。

### 4.3 简化损失函数

DDPM 的核心创新之一：把变分下界简化为一个 MSE 损失：

```
标准变分下界（复杂）:
  L = E_q[-log p_θ(x₀|x₁) + Σ_t KL(q(x_{t-1}|x_t,x₀) || p_θ(x_{t-1}|x_t)) + ...]

DDPM 的简化损失（简单！）:
  L_simple = E_{x₀, ε, t}[ || ε - ε_θ(√ᾱ_t·x₀ + √(1-ᾱ_t)·ε, t) ||² ]
                     ↑          ↑                     ↑
              真实噪声    模型预测的噪声        加噪后的图像
```

这个简化带来了三个好处：

1. **去掉所有常数权重**——不需要调超参数平衡各个损失项
2. **所有时间步权重一致**——早期和后期加噪步骤有一样的训练信号
3. **数值范围稳定**——ε ~ N(0, I)，输出范围已知，不像像素值范围变化大

## 五、U-Net 骨架（架构总览）

DDPM 使用 **U-Net** 作为噪声预测网络 ε_θ。虽然后续文章（LDM 深度解剖）会单独深入 U-Net 的每一层，这里先给出 DDPM 版本的整体骨架，作为理解扩散过程与神经网络如何结合的完整图谱：

```
输入: x_t (噪声图) + t (时间步)
            │
      ┌─────┴─────┐
      │ Time Embed │  ← t 通过 Sinusoidal 编码映射为向量
      └─────┬─────┘
            │
            ▼
      ┌─────────────────────┐
      │   Conv 1×1 投影     │
      └─────────┬───────────┘
                │
    ┌───────────┴───────────┐
    │ DownBlock 1 (64ch)    │──────┐
    │    ResBlock + Attn    │      │ 跳跃连接
    └───────────┬───────────┘      │
                │                  │
    ┌───────────┴───────────┐      │
    │ DownBlock 2 (128ch)   │──────┤
    │    ResBlock + Attn    │      │
    └───────────┬───────────┘      │
                │                  │
    ┌───────────┴───────────┐      │
    │ DownBlock 3 (256ch)   │──────┤
    │    ResBlock + Attn    │      │
    └───────────┬───────────┘      │
                │                  │
    ┌───────────┴───────────┐      │
    │   Middle Block        │      │
    │ ResBlock + Attn + RB  │      │
    └───────────┬───────────┘      │
                │                  │
    ┌───────────┴───────────┐      │
    │  UpBlock 3 (256ch)    │◄─────┘
    │    ResBlock + Attn    │
    └───────────┬───────────┘
                │
    ┌───────────┴───────────┐
    │  UpBlock 2 (128ch)    │◄─────┘
    │    ResBlock + Attn    │
    └───────────┬───────────┘
                │
    ┌───────────┴───────────┐
    │  UpBlock 1 (64ch)     │◄─────┘
    │    ResBlock + Attn    │
    └───────────┬───────────┘
                │
    ┌───────────┴───────────┐
    │  Conv 3×3 输出投影    │
    └───────────┬───────────┘
                │
              输出: ε_θ(x_t, t) —— 预测的噪声
```

### 关键设计点

| 组件 | 作用 | 备注 |
|------|------|------|
| **ResBlock** | 残差连接 + 时间步条件注入 | Time embedding 通过 Scale/Shift 注入特征 |
| **Self-Attention** | 捕捉远距离像素依赖 | 只在低分辨率特征图上做（16×16）以节省计算 |
| **Time Embedding** | 告诉网络"这是第几步" | 使用 Sinusoidal 编码（同 Transformer PE）|
| **跳跃连接** | 把下采样的细节传到上采样 | 保留高频信息，避免生成模糊 |
| **下采样/上采样** | 逐步压缩/恢复空间维度 | 下采样用 stride=2 conv，上采样用转置卷积或插值 |

### Time Embedding 的注入方式

时间步信息如何影响生成过程——这是扩散模型特有的设计：

```
ResBlock 内部:
  输入: h (特征图), t_emb (时间步编码)

  1. h → Conv3×3 → GroupNorm → SiLU → h'
  2. t_emb → Linear → SiLU → Linear → scale, shift
  3. h' = scale * h' + shift  ← AdaGN（Adaptive Group Norm）
  4. h' → Conv3×3 → GroupNorm → SiLU
  5. 残差连接: h_out = h + h'

关键: scale 和 shift 随 t 变化 → 不同时间步看到的特征图"调节"不同
     早期（t 小）→ 保留细节多，后期（t 大）→ 更多去噪
```

## 六、采样过程：从噪声生成图像

### 6.1 DDPM 采样（1000 步，随机性）

```
算法: DDPM 采样

输入: 训练好的 ε_θ，噪声调度 β₁...β_T
输出: 生成图像 x₀

1. x_T ~ N(0, I)              ← 从纯噪声开始
2. for t = T down to 1:
3.     z ~ N(0, I)  (如果 t>1, 否则 z=0)
4.     ε_pred = ε_θ(x_t, t)   ← 模型预测噪声
5.     x_{t-1} = 1/√α_t · (x_t - β_t/√(1-ᾱ_t) · ε_pred) + σ_t · z
6. 返回 x₀
```

第 5 步直观理解：

```
x_{t-1} = 缩放后当前图 - 预测噪声幅度 + 随机抖动
           (去噪方向)      (保持多样性)
```

随机项 z 的加入是必要的——如果没有它，每一步都是确定性的，生成结果会缺少多样性。但这也意味着 **DDPM 采样是随机的**：同一种子每次跑结果不同。

### 6.2 DDIM 加速采样（50-100 步，确定性）

DDIM（Song et al., 2020）的贡献是用一个重写后的采样公式，将采样步数从 1000 降到 50-100，且生成质量不变：

```
DDIM 的关键改动:
  跳过马尔可夫链: 直接定义 q(x_{t-1}|x_t, x₀) 为非马尔可夫形式

DDIM 采样公式:
  x_{t-1} = √ᾱ_{t-1} · x₀_pred + √(1 - ᾱ_{t-1}) · ε_θ(x_t, t)

  其中 x₀_pred = (x_t - √(1-ᾱ_t) · ε_θ(x_t, t)) / √ᾱ_t
```

| 对比 | DDPM | DDIM |
|------|------|------|
| 步数 | 1000 步 | 50-100 步 |
| 随机性 | 每步加随机噪声 | **确定性**（去掉了随机项 z）|
| 一致性 | 同一种子每次不同 | 同一种子永远一样 |
| 速度 | ~数分钟/张 | ~几秒/张 |
| 训练 | — | **直接复用 DDPM 训练的模型** |

**DDIM 的核心价值：** 意识到扩散模型的"马尔可夫链"假设可以放松——不需要在隐空间中逐步转移，可以直接跳到任意步。这使得扩散模型从"理论上能用"变成"实际可用"。

## 七、DDPM 的三大重要局限

| 局限 | 表现 | 后续解决 |
|------|------|---------|
| **推理慢** | 1000 步生成一张图，<1 FPS | DDIM（50 步）、LCM/LDM（1-4 步）、Rectified Flow |
| **无条件生成为主** | 没有有效的条件控制机制 | LDM 的 Cross-Attention 条件注入 |
| **像素空间扩散** | 直接对 256×256×3 图像操作，计算量巨大 | LDM 的潜空间扩散（48× 压缩率）|

这三个局限其实是递进的——**速度问题靠 DDIM 缓解，条件控制靠 LDM 的 Cross-Attention 解决，计算量靠潜空间压缩解决。** 下一篇 LDM 深度解剖会逐一展开。

## 八、总结

> **DDPM 的贡献不是发明了新数学——它找到了一个极简的工程配方（预测噪声 + MSE 损失 + 线性调度 + U-Net），让扩散模型从"理论玩具"变成了"实用引擎"。**

这个配方的各个元素后来被替换/升级了：

| DDPM 原始设计 | 后续替代/升级 |
|--------------|-------------|
| 线性噪声调度 | cosine schedule / sigmoid schedule |
| 1000 步采样 | 50 步（DDIM）→ 1-4 步（蒸馏/LCM）|
| 像素空间 U-Net | 潜空间 U-Net（LDM）→ DiT（FLUX/SD3）|
| 无条件生成 | Cross-Attention 条件注入 → MM-DiT 双向交互 |

但配方的基本框架——**前向加噪 + 反向去噪 → 预测噪声 ε**——至今仍是所有扩散模型共同的技术地基。
