﻿﻿﻿﻿﻿﻿﻿# 🗣️ 语音合成（Text-to-Speech）系统性学习体系

> 将文字转化为自然流利的语音——输入是文本序列，输出是对应的语音波形序列。核心挑战在于：**文本是离散的、稀疏的符号系统，语音是连续的、高维的声学信号**，两者之间的映射充满了歧义（同文异音、异文同音、韵律无标注）。

## 技术演进：6 个范式跃迁

整个 TTS 领域的历史可以拆成 6 个范式跃迁。每次跃迁都在**解决上一轮留下的麻烦**，同时**引入新的问题**。

### 1. 拼接合成（~1990s–2000s）

| 解决的问题 | 留下的麻烦 |
|-----------|-----------|
| 保留真实人声的所有自然细节，无需任何生成模型 | 需要超大录音库（数小时），无法覆盖所有语境；拼接点处有明显不连贯；无法改变说话人/风格 |

### 2. HMM 统计参数合成（~2000s–2016）

| 解决的问题 | 留下的麻烦 |
|-----------|-----------|
| 模型极小（几 MB），灵活可控（改变基频/时长），无需大录音库 | "统计平滑"效应导致声音沉闷、buzzy，远不如拼接自然；相位和人声细节大量丢失 |

### 3. WaveNet + 自回归路线（2016–2018）

| 解决的问题 | 留下的麻烦 |
|-----------|-----------|
| 自然度实现飞跃，首次通过深度学习达到接近人类水平；WaveNet 直接生成波形质量震撼 | 自回归逐采样点生成，生成 1 秒语音需要数万次推理步骤，速度极慢；注意力对齐不稳定 |

### 4. 非自回归路线（2019–2021）

| 解决的问题 | 留下的麻烦 |
|-----------|-----------|
| 并行生成使推理速度提升 100–270 倍，适合工业在线部署；鲁棒性大幅提升 | 韵律多样性不足（"平均化"）；少样本/零样本能力弱于自回归；控制力不如预期精细 |

### 5. 统一端到端模型（2021–2022）

| 解决的问题 | 留下的麻烦 |
|-----------|-----------|
| 消除声学模型+声码器的两阶段管线，端到端联合优化避免中间表征信息损失 | 仍然需要大量配对的文本-语音数据；难以扩展到新说话人/新语言 |

### 6. 大模型 + 零样本（2023–至今）

| 解决的问题 | 留下的麻烦 |
|-----------|-----------|
| 零样本语音克隆（3 秒即可合成任意说话人）；可大规模利用无标注语音数据；多语言/多风格统一框架 | 音质不稳定、存在幻觉（发音错误）；计算成本极高；情感/韵律精细控制仍是开放问题 |

> 这个演进表是整份知识库的**主轴**。每个模块的细节都应该能映射到这个时间线上。

## 四大模块拆解

一个现代 TTS 系统可以从四个层次来理解：

### 1. 信号 / 输入层：文本前端与语音学特征

文本到语音的起点是对输入文本的理解。这涉及文本规范化（数字/日期/缩写的歧义消除）、音素转换（G2P）、韵律预测（边界/重音）。**这一层是 TTS 中最容易被低估但实际最影响自然度的部分。**

- **Tan et al. (2021) "A Survey on Neural Speech Synthesis" [[arXiv](https://arxiv.org/abs/2106.15561)]**：最全面的 TTS 综述，覆盖经典→神经TTS演进，是系统学习 TTS 的最佳入口
- **Taylor (2009) "Text-to-Speech Synthesis" [Cambridge University Press](https://www.cambridge.org/9780521899275)**（教材）：统计参数合成的经典参考书，文本前端章节仍是标准参考文献

### 2. 核心范式层：三大流派

当前 TTS 的核心生成范式可归纳为三大流派：

| 范式 | 核心优点 | 核心代价 | 适用范围 |
|------|---------|---------|---------|
| **自回归（AR）** Tacotron → mel → vocoder | 自然度高、韵律丰富 | 推理慢、对齐不稳定 | ❌ 实时场景 |
| **非自回归（NAR）** FastSpeech → mel → vocoder | 速度快（100×+）、鲁棒 | 韵律偏"平均" | ✅ 工业实时部署 |
| **LLM+Codec** VALL-E / CosyVoice | 零样本、可扩展、统一框架 | 计算成本高、可控性弱 | ✅ 少样本/多说话人 |

**一个贯穿所有范式的设计轴：速度与质量的权衡。** AR 追求极致质量但牺牲速度，NAR 追求速度但损失韵律多样性，LLM+Codec 追求零样本泛化但牺牲可控性。

### 3. 编码器 / 模型架构层：从卷积到 Transformer 到 LLM

| 架构 | 年份 | 贡献 | 局限 |
|------|------|------|------|
| WaveNet (Causal Dilated CNN) | 2016 | 首个生成高质量波形的深度模型 | 自回归逐点生成，极慢 |
| Tacotron (CBHG + Attention) | 2017 | 首个端到端文本→mel 声学模型 | 对齐不稳定 |
| Transformer TTS | 2018 | 用 Transformer 替代 RNN，训练更快 | 仍需自回归 |
| FastSpeech (FFT + Duration Predictor) | 2019 | 非自回归 + 时长预测器，并行生成 | 蒸馏损失，音质不如 AR |
| VITS (VAE + Flow + GAN) | 2021 | 单模型端到端，VAE + 对抗训练 | 训练不稳定 |
| VALL-E (Neural Codec + LM) | 2023 | Codec + Language Model 新范式 | 零样本音质不稳定 |

**Transformer（尤其是各类变体）** 是 2019 年至今的事实标准。后续变体（Conformer、Efficient Transformer）主要是效率优化，没有突破性的 idea 变化。

### 4. 数据范式层：你有多少配对数据？

```
你有多少标注的文本-语音配对数据？
├── < 1 小时 → 零样本路线：VALL-E / VoiceBox / CosyVoice（无需配对或极少配对）
├── 1–10 小时 → 微调路线：预训练模型 + 少量目标说话人数据
├── 10–100 小时 → 标准训练：FastSpeech / VITS 的标准训练量
└── > 100 小时 → Scaling 路线：NaturalSpeech 等大规模训练范式
```

## 学习路径设计

### 目标用户画像

> **用户背景**：具有深度学习基础（Transformer、损失函数、训练流程）的 ML 工程师或研究生，了解音频信号基础（采样率、频谱图），希望系统掌握 TTS 从经典到前沿的全貌。

| 你已经熟悉的 | 你需要补齐的 |
|-------------|-------------|
| Transformer、注意力机制、自回归生成 | 语音的时域/频域表征（mel谱、编解码器） |
| 基本的 NLP 知识（分词、音素概念） | 文本规范化的核心难题（数字/日期消歧） |
| 卷积/RNN/GAN/VAE 基本概念 | WaveNet 的因果扩张卷积结构 |
| 语言模型的基本范式 | 如何用 LLM 范式做 TTS（VALL-E 的思路） |
| — | 声码器（Vocoder）的设计和权衡 |
| — | TTS 的评估方法（MOS / 客观指标 / 常见陷阱） |

### 建议的学习顺序

```
1. **01-文本前端**——快速过，理解"输入侧"的隐性困难，在学后面的模块时能想到"这些细节最后怎么被模型捕捉？"
   ↓
2. **02-声学建模**——核心建模范式，从 AR → NAR → Flow 的演进，理解"为什么非自回归才是工业级解"
   ↓
3. **03-波形生成**——从 WaveNet → GAN → Flow 的声码器演进，理解"从参数到波形"的最后一公里
   ↓
4. **04-统一端到端**——理解 VITS 如何合并前两个阶段的管线，以及为什么这可能是"传统范式的最优解"
   ↓
5. **05-大模型与零样本**——全新范式，理解"LLM 如何颠覆传统 TTS 的建模范式"
   ↓
6. **06-可控性与个性化**——横跨所有范式的控制轴，理解"还有什么问题没有解决"
```

## 当前前沿（2023–2026）：仍然没解决的具体痛点

- **发音幻觉与稳定性**：大模型 TTS 有时会读错字、加词或少词，尤其是在姓名、专业术语等低频词汇上。这是 LLM 范式自带的"智能生成 vs 精确还原"冲突
- **韵律多样性与自然度**：非自回归路线仍然存在"平均化"问题，韵律缺乏人类表达的戏剧性变化。为什么到现在还是难题：因为韵律的标注极其昂贵且主观
- **情感与风格精细控制**：用户想要"第 3 秒到第 5 秒用惊讶语气"，但目前只有粗糙的全局风格标签。问题在于缺乏有标注的情感/韵律数据集
- **跨语言一致性**：多语言 TTS 中的代码切换（中英混说）仍然难以处理，不同语言的音素系统冲突
- **实时性的全栈挑战**：LLM+Codec 范式虽然效果好，但推理延迟高，难以在端侧设备部署
- **评价体系问题**：MOS（Mean Opinion Score）作为黄金标准的存在范式滞后——它需要大量人工评测，不可复现，且在大模型时代无法区分"好听但读错了"和"自然度稍低但全对"的差异。客观指标（CER / WER / F0 RMSE）各有偏颇
