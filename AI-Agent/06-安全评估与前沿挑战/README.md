# 06 — 安全评估与前沿挑战

## 一句话开场

> 你的 Agent 能查数据库、发邮件、操作文件——如果被注入了恶意指令，它能把自己"越狱"然后删掉你所有文件。Agent 的能力越强，造成破坏的潜力越大。这个模块讨论：怎么安全地使用 Agent？以及 Agent 领域还有什么大问题没解决？

## 正文：渐进式理解

**第一层：问题定义。** Agent 的安全问题比 LLM 更严峻。LLM 的安全风险是"输出有害文本"，而 Agent 的安全风险是**"执行有害操作"**——区别就像"说脏话"和"动手打人"。安全评估与前沿挑战解决的问题：**怎么在释放 Agent 能力的同时，把风险控制在可接受范围内？以及当前还没有答案的开放问题有哪些？**

**第二层：核心直觉。** 想象一个超级能干的实习生，你给了他所有权限。他能做的事很多，但他也可能：被钓鱼邮件骗（Prompt 注入）、自己编造数据（幻觉放大）、过度执行（删掉整张表）。你会怎么做？限制权限、设置审批、审计日志——Agent 安全也是同样的思路。

**第三层：方案细节。** Agent 安全的四层防线：① **权限最小化**——Agent 只获得完成任务所需的最小权限，关键工具需人类审批；② **输入过滤与沙箱**——检测注入攻击、环境放在沙箱中执行；③ **行为审计**——记录每一步操作，异常行为检测；④ **人类在环中（HITL）**——高风险操作必须人类确认。

**第四层：不同风险的权衡。**

| 风险类型 | 威胁描述 | 影响级别 | 缓解措施 |
|---------|---------|---------|---------|
| **直接 Prompt 注入** | 用户输入覆盖系统指令 | 严重 | 输入消毒 + 参数化调用 |
| **间接 Prompt 注入** | Agent 读取的文档含恶意指令 | 严重 | 内容隔离 + 敏感操作审批 |
| **工具误调用** | Agent 不确定时错误调用工具 | 中高 | 调用确认 + 权限分级 |
| **幻觉传播** | 幻觉结果被当真并继续操作 | 中 | 事实核查 + 结果验证 |
| **过度自主性** | Agent 执行了用户没想让它做的事 | 中 | 审批环 + 操作范围限制 |

**第五层：总结升华。** Agent 安全是"能力"的逆向面——能力越强，安全越重要。当前 Agent 安全的进展严重落后于 Agent 能力的进展。这个模块放在最后，既是提醒也是警告：安全不是可以"以后再加"的功能——它应该从第一天就融入系统设计。

## 学习目标

读完你能：

- 用一句话说清 Agent 安全和 LLM 安全的区别：LLM 安全是"说坏话"，Agent 安全是"干坏事"
- 面对一个 Agent 系统，设计其安全防护的四层防线
- 理解 Prompt 注入在 Agent 场景中为什么更危险
- 指出当前 Agent 领域 3 个具体的开放问题
- 给出"Agent 自主度 vs. 人类可控性"的权衡建议

## 精选论文

**Zhou et al. (2023) "WebArena: A Realistic Web Environment for Building Autonomous Agents"** — [arXiv](https://arxiv.org/abs/2307.13854)

- **一句话定位**：最接近真实场景的 Agent 评估环境
- **阅读重点**：第 3 节（环境设计和任务构成）
- **时间分配建议**：关注评估设计思想
- **与本模块的关系**：Agent 评估基准的代表

**LLM Safety Survey (2024) "Large Language Model Safety: A Holistic Survey"** — [arXiv](https://arxiv.org/abs/2412.17686)

- **一句话定位**：LLM 安全的全面综述，覆盖 Agent 安全章节
- **阅读重点**：Agent 相关安全章节、攻击分类与防御框架
- **时间分配建议**：关注安全分类和 Agent 特有的风险
- **与本模块的关系**：提供 Agent 安全的学术全景

**GUI Agents Survey (2024) "GUI Agents: A Survey"** — [arXiv](https://arxiv.org/abs/2412.13501)

- **一句话定位**：图形界面 Agent 的系统综述
- **阅读重点**：Agent 交互范式和安全挑战章节
- **时间分配建议**：关注 Agent 在 GUI 操作中的安全约束
- **与本模块的关系**：多模态 Agent 的前沿方向
